# Student-Performance-Prediction
AI-Based Student Performance Prediction Using Python and Machine Learning
🎓 AI-Based Student Performance Prediction System

📌 Project Overview

The AI-Based Student Performance Prediction System is a Machine Learning project developed using Python and Google Colab.

It predicts students' final marks based on attendance, study hours, previous marks, and assignment marks.

🎯 Objectives

- Predict student academic performance.
- Analyze student learning patterns.
- Compare Machine Learning models.
- Display predictions through an interactive dashboard.

🛠️ Technologies Used

- Python
- Google Colab
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Joblib

🤖 Machine Learning Algorithms

1. Linear Regression
2. Random Forest Regression

📊 Dataset Features

- Attendance
- Study Hours
- Previous Marks
- Assignment Marks
- Final Marks

📈 Model Performance

Linear Regression:

- MAE: 5.01
- RMSE: 5.78
- R² Score: 0.83

Random Forest:

- MAE: 6.60
- RMSE: 7.97
- R² Score: 0.68
